Privacy Policy

Applies to the Shorts Studio publishing tool.

Shorts Studio uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses it

Shorts Studio is used only by its developer to publish videos to the developer's own YouTube channel. It is not offered to other users.

Data accessed

The tool requests only the youtube.upload permission. It uses this permission solely to upload videos (with title, description and tags) to the authorizing account's own channel. It does not read, collect or store any other Google or YouTube user data, viewer data, comments or analytics.

Storage and security

The OAuth refresh token is stored only as an encrypted secret in the developer's private GitHub repository and is used only by the automated upload step. No personal data is stored, sold or shared with third parties. No cookies or tracking are used.

Revoking access

Access can be revoked at any time from Google Account → Security → Third-party connections. After revocation the stored token stops working and is deleted from the repository secrets.

Shorts Studio

Shorts Studio is a private, single-user publishing tool operated by the developer matali. It produces short 3D-animated educational science videos (YouTube Shorts) and uploads them to the developer's own YouTube channel using the YouTube Data API.

What it does

  • Renders an original 3D animation, narration and music for each episode.
  • Uploads the finished video, its title, description and tags to the developer's own channel via videos.insert.

The tool is not offered to the public, has no user accounts and does not access any other person's YouTube or Google data.
